Fitflow — Fitness App UI Design

Advanced-level UI/UX design project: a full-featured mobile app UI for a fitness platform offering personalized workout routines based on user goals, preferences, and fitness level.

Project: Fitness App UI Design with Personalized Workout Recommendations 
Tool: Figma 
Difficulty: Advanced

1.Overview:

Fitflow is designed around a locked example persona — a user with a Weight Loss goal, Intermediate fitness level, and a preference for Home Workouts, Cardio, and Strength Training. Every screen in the flow reflects this persona consistently, from onboarding through the dashboard, workout plan, and progress tracking.

3.Featured screens: 

I) Splash Screen - Branding, logo mark.

II) Login Screen - Auth flow, reusable input field component.

III) Onboarding – Goal Selection, Personalization flow entry point.

IV) Dashboard - Hero workout card, weekly tracker, progress bar, achievement badge, recommendations.

V) Workout Plan Page - Filters, "Today" highlighting, category tagging.

VI) Workout Detail Screen	- Video demo area, sets/reps list, completed/current/upcoming states.

VII) Progress Tracker	- Bar chart, line chart, achievement badges.

VIII) Profile Screen (Dark Mode)	- Stats/progress display + dark mode extra credit.

See /screens for these images at full resolution.
